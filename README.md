# Wind-Data-Report
**1. กรองข้อมูล (Filtering)**

โค้ดจะไปดึงวันที่ Commissioning Date (วันที่เริ่มเก็บข้อมูลจริง) ข้อมูลของเดือนนั้นๆ จะถูกนำมาเทียบ หากมีข้อมูลที่เกิดขึ้น ก่อน วันที่ Commissioning Date ข้อมูลเหล่านั้นจะถูกตัดทิ้ง (เพื่อป้องกันไม่ให้ข้อมูลช่วงทดสอบระบบ หรือช่วงที่ยังติดตั้งไม่เสร็จ มาทำให้ค่า % Recovery ผิดเพี้ยน)

**2. การประมวลผลข้อมูลและจัดกลุ่มเซ็นเซอร์ (Data Processing & Grouping)**
   
นำข้อมูลรายเดือนทั้งหมดที่ผ่านการกรองมาต่อกันเป็นตารางเดียว (df_all_years) เรียงลำดับตามเวลา และมีตัวกรองอีกชั้นคือ ตัดข้อมูลที่เวลาเกินกว่าปัจจุบันทิ้ง
แยกชนิดเซ็นเซอร์จาก "ชื่อคอลัมน์" ความสูง: ค้นหาตัวเลขที่ตามด้วย m หรือ M (เช่น 159.8m) แล้วนำมาปัดเศษเป็นจำนวนเต็ม (160m) 
ประเภทอุปกรณ์อ่านจากชื่อ เช่น WS / ANEM = ความเร็วลม, WD / VANE = ทิศทางลม, T = อุณหภูมิ, P / MB = ความกดอากาศ
ทิศทาง: ตัดคำด้วยเครื่องหมาย _ แล้วเช็คหาคำที่เป็นทิศทาง เช่น NW, NNW, SE,SSE
การสร้างกลุ่มเซ็นเซอร์ (Grouping Base Key): นำ ข้อมูลทั้ง 3 ส่วนมาประกอบร่างกันเป็น Base Key เช่น WS_160m_N คอลัมน์ไหนที่มี Base Key ตรงกัน จัดเข้ากลุ่มเดียวกัน
คำนวณ % Recovery: ข้อมูลที่ได้จากการคลีนมาหารด้วยจำนวนแถวเวลาทั้งหมด แล้วคูณ 100 

**3. การวาดกราฟ (Visualization)**

การให้สี (Color Coding):
forestgreen (เขียว): ข้อมูลมีอยู่จริง และภาพรวมทั้งปีของเซ็นเซอร์นี้ทำงานได้ดี (Recovery >= 90%)
#2a445e (น้ำเงินเข้ม): ข้อมูลมีอยู่จริง แต่ภาพรวมทั้งปีของเซ็นเซอร์นี้เริ่มมีปัญหา (Recovery < 90%)
#E0E0E0 (เทาอ่อน): ช่วงเวลาที่เกิด Downtime ไม่มีข้อมูล

แกน:แกน X ให้อยู่เฉพาะช่วงที่มีข้อมูลจริง (min() ถึง max()) จัดฟอร์แมตแกน X ให้เป็น "เดือน ปี" ปรับแต่งสีตัวอักษรและเส้นขอบให้เป็นสีเทาเข้ม (#333333) และวาด Legend
(คำอธิบายสัญลักษณ์) ไว้ที่ด้านล่างสุดของกราฟ
